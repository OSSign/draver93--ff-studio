# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [Draver93/ff-studio](https://github.com/Draver93/ff-studio/) project.

## Where are the signed binaries published?
The signed binaries are published by the author on [Draver93/ff-studio](https://github.com/Draver93/ff-studio).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/draver93--ff-studio/actions).
